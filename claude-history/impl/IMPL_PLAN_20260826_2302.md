## 1. H1 태그 디자인

### 요구사항
- H1 텍스트 크기 35px
- 문서 컨테이너 기준 가운데 정렬

### 설계
| 모드 | 적용 지점 | 방법 |
|---|---|---|
| Read | `.rv-content h1` | `font-size: 35px; text-align: center` |
| Write | `.cm-h1` | `font-size: 35px` (기존 `1.5em`) |
| Write | `.cm-h1-line` | `text-align: center` |

Write Mode 의 `.cm-h1` 은 `Decoration.mark` 라 **인라인 요소**다.
`text-align` 은 블록 컨테이너 속성이므로 mark 로는 적용되지 않는다.
→ `HeadingDecorator` 에서 `level === 1` 일 때 `Decoration.line({class:'cm-h1-line'})`
   을 추가해 `.cm-line` 자체에 클래스를 건다.

`RangeSetBuilder` 는 `from` 오름차순 입력만 허용하므로,
line decoration 은 해당 라인의 badge/mark 데코레이션보다 **먼저** 넣는다.

두 모드의 값(35px)을 반드시 일치시켜야 Write↔Read 전환 시 레이아웃이 흔들리지 않는다.

## 2. 이미지 커스텀 속성 문법

### 문법
```
![대체텍스트 | ["title":"제목", "title-position":"top"]](경로)
```

- 라벨(`[]` 안쪽) **맨 끝**에 `| [ ... ]` 블록을 붙인다.
- 블록 안에는 `"key":"value"` 쌍을 콤마로 나열한다.
- `title-position`: `top` | `bottom`. 생략하거나 값이 이상하면 **`bottom`**.
- `title` 이 없으면 캡션을 출력하지 않는다.
- 속성 블록이 없으면 기존 마크다운과 100% 동일하게 동작한다(회귀 없음).

### 확장성 사전 설계 (요청 사항의 핵심)
속성을 대괄호 한 덩어리로 묶었기 때문에:
- `img-size`, `img-position` 등 키가 추가돼도 **파서를 고칠 필요가 없다**. 키만 더 읽으면 된다.
- 파서를 "이미지 전용"이 아니라 **라벨 문자열 → `{ label, attrs }`** 범용으로 작성했으므로,
  향후 하이퍼링크 `[텍스트 | ["title":"..."]](주소)` 에 그대로 재사용할 수 있다.
  (`HyperlinkDecorator` 는 현재 `LINK_RE` 가 중첩 대괄호를 허용하지 않으므로,
   링크에 속성을 붙일 때 `ImageDecorator` 와 동일한 방식으로 정규식만 확장하면 된다.)

### 파서 계약 — `src/shared/lib/markdown/inlineAttrs.ts` (신규)
```ts
parseLabelAttrs(rawLabel) -> { label: string; attrs: Record<string,string> }
readTitleSpec(attrs)      -> { title: string; position: 'top'|'bottom' } | null
```
- 속성 블록 정규식: `/\|\s*\[([^[\]]*)\]\s*$/` — **라벨 끝에만** 허용해야
  본문 텍스트에 들어 있는 `|` 와 충돌하지 않는다.
- 키는 소문자로 정규화한다.

### 렌더 출력
| 모드 | 출력 |
|---|---|
| Read | `<figure class="rv-figure">` + `<figcaption class="rv-figure-caption rv-figure-caption-{top\|bottom}">` (position 에 따라 DOM 순서 결정) |
| Write | `span.cm-image-widget` 안에 `span.cm-image-caption` 을 img 앞/뒤에 배치 |

`.rv-figure { width: fit-content }` 로 figure 를 실제 이미지 폭에 맞춘다.
컨테이너 폭 기준으로 캡션을 가운데 정렬하면 좁은 이미지에서 캡션이 떠 보인다.

## 5. 남은 과제 (이번 범위 밖)

- `HyperlinkDecorator.LINK_RE` 는 아직 중첩 대괄호를 허용하지 않는다.
  링크 속성 문법을 열 때 `ImageDecorator` 와 동일하게 확장 필요.
- `HyperlinkDecorator` 에 `!` 접두 가드가 없어 일반 이미지 `![alt](src)` 의
  `[alt](src)` 부분에도 매칭된다(기존 이슈). 링크 작업 시 함께 정리 권장.
- `MindView` 는 커스텀 렌더러 없는 순정 `Marked` 를 쓰므로 노드 프리뷰에는
  코드펜스 타이틀/이미지 캡션이 반영되지 않는다.
