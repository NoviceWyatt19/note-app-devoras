# Antigravity Harness Rule

## 1. 켄텍스트 최소화 원칙
- 대화 시작 시 반드시 `.harness/session_bridge.md`와 `.harness/ticket_board.md`만 먼저 읽으세요.
- 이전 대화 기록 전체를 요구하지 마세요. 필요한 정보는 오직 하네스 파일에만 존재합니다.

## 2. 작업 종료 프로토콜 (Handover)
- 답변을 마치거나 코드를 수정한 후에는 반드시 `.harness/session_bridge.md`에 다음을 기록해야 합니다:
  - 현재 수행한 작업 요약 (최대 3줄)
  - 다음 단계의 챗(디버깅 또는 커밋)이 알아야 할 핵심 변경 코드 및 주의점
