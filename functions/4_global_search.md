# Feature Ticket: 4. 전역 검색
**Status**: PLANNED
**Target Release**: v0.4.5
**Priority**: Medium
**Date**: 2026-07-15

---

## 1. 개요 및 기능 목표
현재 활성화된 워크스페이스 내 모든 마크다운 파일들의 파일명과 본문 텍스트를 실시간으로 색인/검색하고, 매칭된 결과 라인 목록을 보여주어 해당 위치로 빠르게 점프할 수 있는 전역 검색(Global Search) 패널을 구현한다.

## 2. 요구 사항 및 유스케이스
- **키워드 실시간 검색**: 사용자가 입력한 단어에 대해 워크스페이스 전체 디렉터리를 스캔.
- **파일명 및 본문 결과 분리**: 파일 제목 매치와 텍스트 본문 매치를 가독성 있게 분류하여 출력.
- **하이라이팅 및 매치 라인 노출**: 검색된 텍스트 주변의 맥락(Context Line)을 보여주고 일치 문구 강조.
- **점프 네비게이션**: 검색 결과 클릭 시 해당 파일이 탭에 열리고, 검색어가 위치한 블록과 커서 오프셋으로 즉시 포커스 이동.

## 3. 기술적 구현 설계 (FSD 아키텍처)
- **Shared Layer (`fs.ts` 또는 독립 유틸)**:
  - 워크스페이스 전체를 고속 스캔하고 정규식 또는 단순 문자열 포함 여부로 필터링하는 `searchWorkspace(workspacePath: string, query: string): Promise<SearchResult[]>` 구성.
- **Features/Widgets Layer (`GlobalSearch.tsx`)**:
  - 좌측 사이드바 패널 또는 전역 모달 팝업(`Cmd+Shift+F`) 형태로 검색 인터페이스 제공.

## 4. 작업 체크리스트
- [ ] 워크스페이스 파일 전체 텍스트 고속 풀 스캔 유틸리티 작성
- [ ] 전역 검색 사이드바 위젯 마크업 및 입력 스로틀링(Debounce) 적용
- [ ] 파일명 매칭 및 본문 스니펫 추출 파서 작성
- [ ] 검색 결과 리스트 클릭 시 에디터 로드 및 특정 라인/블록 포커싱 연동
- [ ] 대용량 폴더 스캔 시 성능 지연 최소화 (비동기 청크 스캔 또는 Rust/Tauri 네이티브 백그라운드 탐색 연동)
